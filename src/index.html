뉘앙스

말의 무게와 거리, 일상의 결인지 격식의 결인지.

예시

영어 화자의 귀에 자연스러운 예와 걸리는 예.

그리고 같은 장면을 세 가지로 말한 문장을 견줍니다.

We don't have much time.

  3. 마지막에는 직접 영어로 써 보고, 모범 답과 견줍니다.
  4. 읽다가 걸린 문장은 해설기에 넣어 봅니다.

앞으로 다룰 것

  1. 기본동사 14개: 지금 하고 있습니다.
  2. 섞어 풀기: on, out, up, over 같은 불변화사와 to, at, of, as를 동사와 섞어 풉니다.
  3. 더 많은 책: 다른 원서의 장면으로 연습을 넓힙니다.
  4. 어순: 아는 것은 앞에, 새것은 뒤에. 동사 자리에 오면 동사로 들리는 영어의 감각을 따로 다룹니다.
